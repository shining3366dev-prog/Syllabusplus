About

One home. Many tools.

noname is a small, growing ecosystem of focused tools. We build one thing at a time, and we build it to last.

What noname is

noname is an umbrella for a handful of carefully made web apps. Instead of one bloated site that does everything poorly, each tool is its own “branch” — small, fast, and focused — sharing the same calm design, the same languages, and the same front door.

The first branch: sbplus

sbplus is a study companion for school years S1–S7. It turns dry syllabus material into interactive lessons — readable articles, rendered maths, embedded demos and quick quizzes — in English, German and French.

How we build

  • Less, but better. Every screen earns its place. If it isn’t used, it’s cut.
  • Quiet by default. Warm paper, ink text, generous space — content first.
  • One ecosystem. Each new branch should feel like it always belonged.
